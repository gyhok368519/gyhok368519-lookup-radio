【为什么上次失败了】
  GitHub 网页的「Upload files」【不能拖文件夹】。
  你把 scripts/ 和 .github/ 拖进去，GitHub 只保留文件名，
  层级全丢了 —— 15 个文件全平铺在根目录。
  结果：页面能看，但工作流文件躺在根目录，Actions 认不出来。

【这次的方法：结构文件全部用 Create new file】
  在「Add file -> Create new file」的文件名框里直接敲斜杠，
  GitHub 会自动建出目录层级。这是官方支持的方式，最稳。
  （Upload files 只用一次：传 index.html，那个不需要目录）

  （如果嫌麻烦，可以不清空，直接按下面覆盖也行）

★ 上传完怎么验证（关键）
----------------------------------------------------------------
  1. 仓库首页应该能看到：
       .github/          ← 文件夹
       scripts/          ← 文件夹
       index.html
       README.md
       requirements.txt

  2. 点顶部「Actions」标签（看不到就点右边的「...」三个点）

  3. 左边栏应该出现：Auto refresh lockup radar
     如果只有 pages-build-deployment，说明 .github/workflows/ 还是没建对

  4. 点「Auto refresh lockup radar」-> 右边点「Run workflow」
     -> 再点绿色「Run workflow」按钮

  5. 等 1~2 分钟刷新，看有没有绿色勾
     点进去看「Fetch data and rebuild dashboard」的日志
